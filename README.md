### Featured work

#### 🏛️ Uniform Civil Code Platform · [ucc.uk.gov.in](https://ucc.uk.gov.in)
Uttarakhand's statewide UCC system, built on React, NestJS and MongoDB.
- Built the **certificate, payment and payment receipt** modules. Certificates are rendered server-side from HTML templates to PDF.
- Built the **multi-level officer workflow** (review, approve, reject) with the payment gateway integrated into the flow.
- Added a **filtered data export** so officers can download records for any service.
- Implemented **sign-up, JWT authentication and role-based access control**, enforced in both the NestJS API and the React frontend.

#### 🌐 Apuni Sarkar · Uttarakhand citizen services portal
A portal with 100+ digital services and 100,000+ users.
- One of four backend engineers. I designed and built REST APIs for **40+ services** (4–5 endpoints each) with NestJS, Node.js and MongoDB.
- **Rewrote slow MongoDB aggregation pipelines** and added **Redis caching** on high-traffic read paths to speed up API responses.

#### 📊 PM Gati Shakti Uttarakhand
A planning platform for state officials. I built the officer dashboards, with data tables, charts, filters, summary metrics and Excel export (React, Node.js, MongoDB).

#### 🖥️ e-District Uttarakhand & ITDA website · [itda.uk.gov.in](https://itda.uk.gov.in)
- Built frontend and backend features for e-District Uttarakhand (React, Node.js, MongoDB, PostgreSQL).
- Designed and launched the official ITDA Uttarakhand website with Next.js, React and TypeScript.
